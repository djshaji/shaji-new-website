## Amp Rack / Opiqo

I created and lead development of **Amp Rack / Opiqo** under Acoustix Audio Engineering. It’s an open-source multi-effects processor and LADSPA/LV2 plugin host for Android, Linux and Windows. It brings together guitar effects, bass amp simulators, synthesizers, impulse response loaders and neural amp modelling.

## Computational research pipelines

I build reproducible Python workflows for literary text analysis with Hugging Face Transformers, spaCy, pandas and dimensionality reduction. I use Runpod and Kaggle for experiments that need GPU compute.

## Web and cloud projects

My projects include `clover-cloud-file-manager` and `viola-biometric`, alongside full-stack LAMP applications. I work primarily with MIT- and GPL-licensed software. Explore my [GitHub profile](https://github.com/djshaji/) for the code.
